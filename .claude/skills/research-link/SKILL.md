# research-link

1. Read the link (repo README, post, article). If it cannot be read, say so and ask for the name or text.
2. Decide: **USE** (adopt now), **TEST** (try it on one ZAO thing), **WATCH**, or **SKIP**, with one line on why, in ZAO terms.
3. Note stars, licence, cost, what it needs to run, and any risk (no licence, no guardrails, paid API).
4. Write `research/<topic>/<number>-<slug>/README.md` in ZAODEVZ/ZAOresearch with the frontmatter the repo uses, next free number in 1900-1999.
5. Add it to the open research PR (or one new PR from fresh main if none is open). Changelog row last.
6. Reply with the PR link and the verdict in one line.
